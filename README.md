# Sistem Perpustakaan API

Project backend API sistem perpustakaan berbasis FastAPI yang dikembangkan dari template pembelajaran dengan penambahan fitur pengelolaan denda, peminjaman, dan relasi database.

## ✨ Features

* CRUD data buku
* CRUD data siswa
* CRUD data penulis dan kategori
* Sistem peminjaman buku
* Sistem pengembalian buku
* Pengelolaan denda keterlambatan
* Relasi database menggunakan SQLAlchemy
* REST API endpoint

## 🛠 Tech Stack

* Python
* FastAPI
* SQLAlchemy
* MySQL
* Uvicorn

## 🚀 Installation

1. Clone repository

```bash
git clone https://github.com/jaqckline/sistem-perpustakaan-api.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Jalankan server

```bash
uvicorn main:app --reload
```

4. Open browser

```text
http://127.0.0.1:8000/docs
```
